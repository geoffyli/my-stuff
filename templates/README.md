# Daily Note

Template: `daily-note.md`

## Usage (Windows work device)

1. Copy `daily-note.md` → local notes folder (outside this repo).
2. Rename to `YYYY-MM-DD.md` (today's date).
3. Replace `YYYY-MM-DD` heading with today's date.
4. Fill in through the day.

## Rule

Daily notes never get committed back to this repo. They contain work
content and stay local on the work device. This repo only holds the
template.

## Sections

- **Tasks** — checklist, planned + checked off as done.
- **Notes** — useful info, links, things learned.
- **Reflection** — how the day went, feeling.
